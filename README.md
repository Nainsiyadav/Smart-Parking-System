# 🚗 Smart Parking System

A Python-based Smart Parking System developed as a **group project by a team of 5 members**.

## 📌 Project Overview

The Smart Parking System is designed to manage vehicle parking efficiently using Python, Data Structures, and a Tkinter graphical user interface.

## ✨ Features

- Manage parking slots.
- Add and remove vehicle parking records.
- Search parking records.
- Sort parking information.
- Display parking details through a Tkinter GUI.
- Analyze search performance using graphical visualization.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **GUI:** Tkinter
- **Data Structures:** Dictionary, Deque
- **Algorithms:** Linear Search, Binary Search, Bubble Sort
- **Visualization:** Matplotlib

## ▶️ How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Install Matplotlib:

```bash
pip install matplotlib
```

4. Run the application:

```bash
python gui.py
```
